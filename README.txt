배팅오목 온라인
1. Node.js 18 이상 설치 후 이 폴더에서 npm start 실행.
2. http://localhost:3000 접속. 같은 컴퓨터에서는 별도 브라우저/시크릿 창으로 테스트.
3. 친구와 인터넷 대결하려면 Node.js 웹 서비스 호스팅에 이 폴더를 배포. 시작 명령 npm start, 포트는 PORT 환경변수를 자동 사용. 공개 HTTPS 주소에서 방 만들고 초대 링크 공유.
서버는 메모리에 방을 저장하므로 재시작하면 방이 사라집니다. 단일 서버 인스턴스 사용. 실시간 갱신은 0.7초 폴링. 상대 배팅과 포인트는 API에서 공개하지 않습니다. 실명이나 현금 사용 없음.
